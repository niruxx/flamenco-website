Your desktop, expressive.

Flamenco is a complete Material Design 3 Expressive desktop shell for the niri scrolling compositor and Hyprland. It includes the bar, launcher, control center, notifications, lock screen, dock and a full Settings app, all in one look that carries through to your Qt and GTK apps.

favoriteWhy Flamenco

One shell. Everything in it.

Flamenco replaces the usual mix of bar, notification daemon, wallpaper tool, lock screen and config files with one shell that looks and works the same everywhere.

palette

One look, everywhere

Eighteen palettes in dark and light, your own accent and text colors, or colors from your wallpaper. Qt, GTK and KDE apps, cursors and icons all follow along, and switching palettes cross-fades across the whole shell.

settings

A real Settings app

40 pages, from keyboard shortcuts and displays to online accounts, the firewall and Flatpak permissions. Search any setting with Ctrl F. Every change applies live, with no config files to edit by hand.

view_column

Made for niri

Writes a complete, validated niri config. Also runs on Hyprland, with either the Lua or the classic config.

verified_user

Safe by default

Config edits are checked with niri validate and backed up first. Display changes revert on their own after 15 seconds.

fit_screen

Fits any screen

The bar measures itself and compacts step by step on narrow or rotated screens. Popouts scroll instead of overflowing.

battery_charging_full

Batteries included

A built-in notification daemon, lock screen with fingerprint unlock, live video wallpapers, device pop-ups, OSD, hot corners, screenshots and screen recording. Prefer fuzzel or mako? Flamenco themes those for you too.

extension

Plugins, including other shells'

Add bar widgets and launcher extensions from a git link. Flamenco also runs plugins made for Noctalia Shell and DankMaterialShell, in its own look.

loginFlamenco Greeter

Your theme, from the first screen.

Flamenco Greeter is a login screen for greetd, built from the same components as the shell's lock screen, so logging in, locking and unlocking all look like one screen.

  • palette
    Your theme at loginPalette, fonts, avatar and wallpaper, live video ones included, come from your Flamenco settings or Settings → Lock & Login.
  • fingerprint
    Fingerprint readyThe reader listens as soon as you're picked, and a typed password always works.
  • group
    Every userA user picker with avatars. Each user's own theme cross-fades in as you switch.
  • widgets
    WidgetsPress and hold the background to add a clock, calendar, weather, battery, system info or a note.
  • health_and_safety
    Never a black screenIf the login screen can't start, you get a text login with the reason, and flamenco-greeter doctor says what to run next.
  • encrypted
    Private by designOnly what the login screen needs leaves your home folder, into a folder only the greeter can read.

downloadInstall

Up and running in minutes.

Flamenco ships as an Arch Linux package and installs from source on any distro. Install the shell first; the greeter builds on it.

  1. Install the dependencies

    You need quickshell (0.2 or newer), a compositor (niri or hyprland) and python3. The icon font and Google Sans fonts come bundled. Everything else is optional and switches on one feature each. On Arch:

    $ paru -S quickshell niri \
        networkmanager brightnessctl matugen-bin cliphist wl-clipboard gammastep \
        qt5ct qt6ct adw-gtk-theme qt6-imageformats power-profiles-daemon
    chevron_rightWhat each optional package enables
    PackageEnables
    networkmanagerNetwork status and Wi-Fi control
    brightnessctlScreen and keyboard brightness sliders and OSD
    matugenThe "From wallpaper" palette
    cliphist + wl-clipboardClipboard history in the launcher
    gammastepNight light
    qt5ct, qt6ctTheming Qt apps
    adw-gtk-themeGTK 3 apps that look like libadwaita apps
    qt6-imageformats.webp wallpapers
    qt6-multimedia, qt6-multimedia-ffmpeg, ffmpegLive (video) wallpapers
    fuzzel, makoUse fuzzel as the launcher or mako for notifications, themed by Flamenco
    power-profiles-daemon, upower, bluezPower profile tile, battery, Bluetooth
    fprintdFingerprint enrolling and unlock
    wf-recorder or gpu-screen-recorderScreen recording
    cavaThe audio visualizer

  2. Install Flamenco

    Install the latest build straight from GitHub with pacman (Arch Linux and derivatives):

    $ sudo pacman -U https://github.com/niruxx/Flamenco/raw/main/build-history/flamenco-shell-0.55.0-1-any.pkg.tar.zst

    Build the Arch package from a fresh checkout and install it in one go:

    $ git clone https://github.com/niruxx/Flamenco.git
$ cd Flamenco/packaging/arch
$ makepkg -si

    Install to ~/.local without a package, or run straight from the checkout while you hack on it (edits hot-reload):

    $ git clone https://github.com/niruxx/Flamenco.git && cd Flamenco
$ make install   # → ~/.local/share/flamenco-shell + ~/.local/bin/flamenco
# or
$ make dev

    Then check that everything is found:

    $ flamenco doctor

  3. Hook it into your compositor

    Write a complete niri config for Flamenco. Your keyboard, display and cursor settings are kept, the old file is backed up, and the new one is checked with niri validate before anything changes.

    $ flamenco niri-config           # add --print to look first

    Flamenco writes hyprland.lua if you already have one (or no config yet), otherwise hyprland.conf. Your old config is backed up.

    $ flamenco hyprland-config        # or --lua / --conf to choose, --print to look first
    warning

    The new config doesn't start any other shell. If you used waybar, swaybg, DMS or similar, they're gone; two shells would fight over the bar, notifications and wallpaper.

  4. Log in and make it yours

    Log out and pick niri (or Hyprland) at the login screen. The first time the shell starts, Flamenco Setup walks you through displays, colors, icons, wallpaper, sound, Bluetooth, screen sharing and keyring. Each step is the real Settings page, so changes apply right away.

    $ flamenco run --fg    # start by hand in the foreground (Ctrl+C to stop)
$ flamenco restart     # after an upgrade
$ flamenco setup       # run the first-run setup again
    lightbulb

    Even if the shell doesn't start, the config still works: Mod T opens a terminal and Mod Shift E quits niri.

  1. Install the greeter

    You need Flamenco Shell (the greeter reuses its theme code), greetd, quickshell, python and a compositor (niri, hyprland or sway). Add fprintd for fingerprint login and qt6-multimedia for live wallpapers.

    $ sudo pacman -S --needed greetd quickshell niri
$ sudo pacman -U "https://github.com/niruxx/flamenco-greeter/raw/main/History%20Builds/flamenco-greeter-0.4.0-1/flamenco-greeter-0.4.0-1-any.pkg.tar.zst"

    Pacman's hooks create the greeter user and its data folder for you.

    $ git clone https://github.com/niruxx/flamenco-greeter.git
$ cd flamenco-greeter/packaging/arch
$ makepkg -si
    $ git clone https://github.com/niruxx/flamenco-greeter.git && cd flamenco-greeter
$ sudo make install                                  # installs to /usr
$ sudo systemd-sysusers && sudo systemd-tmpfiles --create

    If Flamenco Shell isn't at /usr/share/flamenco-shell/shell, add SHELL_DIR=/path/to/flamenco-shell/shell to make install.

  2. Try it in a window first

    Preview the greeter with your current theme before switching anything on. Any password except wrong "logs in", and nothing is actually started.

    $ flamenco-greeter preview

  3. Turn it on

    This shows what it will write and asks before changing anything. It points greetd at the greeter, makes greetd your display manager (replacing SDDM, GDM or similar), and offers fingerprint login if it finds a reader.

    $ flamenco-greeter enable          # niri; or: enable hyprland | enable sway

  4. Bring your theme across

    Copy your palette, wallpaper and avatar to the login screen. You can also set the login screen's wallpaper, fonts, sessions, users and power buttons in Flamenco's Settings → Lock & Login and press Apply. To keep your theme in sync automatically:

    $ flamenco-greeter sync
# optional: sync on every change, with no password prompts
$ sudo usermod -aG greeter $USER   # then log out and back in
$ systemctl --user enable --now flamenco-greeter-sync.path

  5. Check, and reboot

    The doctor checks packages, greetd, PAM, the interface itself and the logs, and puts the fix under anything that's wrong. It should end with Everything looks right.

    $ sudo flamenco-greeter doctor
    chevron_rightAdd widgets to the login screen

    Press and hold the login screen's background to add a clock, calendar, weather, battery, system info or a note. Everyone who logs in sees the same layout.

    $ flamenco-greeter widgets list      # what's on the login screen
$ flamenco-greeter widgets lock      # stop anyone editing them
$ flamenco-greeter widgets reset     # remove them all
    chevron_rightSet up fingerprint login 
    $ sudo pacman -S fprintd
$ fprintd-enroll                         # enroll a finger for your user
$ flamenco-greeter fingerprint enable    # adds pam_fprintd to /etc/pam.d/greetd (backed up first)
$ flamenco-greeter fingerprint status
    undo

    Changed your mind? Switch back with sudo systemctl enable -f sddm (or gdm, …) and reboot.

supportHelp

Something not right?

Start with flamenco doctor (or Settings → System check). It lists anything missing and gives you the exact command to install it.

Black screen after logging in to niri

Switch to a text console with Ctrl Alt F3, log in, and run flamenco doctor.

In a virtual machine this is almost always missing 3D acceleration: niri has no software renderer. Turn on 3D in the VM settings (virt-manager: VirtIO video with 3D acceleration and OpenGL on the Spice display; VirtualBox: VMSVGA with 3D acceleration).

Otherwise: if Mod T opens a terminal but there's no bar or wallpaper, the shell didn't start. Check flamenco logs or run flamenco run --fg.

Icons show up as words ("apps", "settings")

The icon font didn't load. Run flamenco doctor to check that MaterialSymbolsRounded.ttf is installed with the shell, then restart the shell.

Plain colored background, no wallpaper

~/Pictures/Wallpapers is missing or empty. Add images, or point Settings → Wallpaper → Folder at another folder. If the wallpaper flickers, another wallpaper program (swaybg, swww, DMS) is still running; remove it from your niri config.

Qt apps ignore the theme

QT_QPA_PLATFORMTHEME isn't set to qt6ct. The niri config that Flamenco writes sets it; log in again and restart the app.

A display change left a blank screen

Wait 15 seconds and it reverts on its own. If you already kept it, restore ~/.local/state/flamenco/backup/niri-config.before-displays.kdl.

The login screen shows a text login, or keeps restarting

If you got the text login, log in there; it means the greeter couldn't start and says why. Otherwise switch to another console with Ctrl Alt F2 and log in. Then:

$ sudo flamenco-greeter doctor

It names the broken piece and the command to fix it. To go back to your previous display manager meanwhile: sudo systemctl enable -f sddm (or gdm) and reboot.

The login screen broke after updating Flamenco Shell

The greeter uses the shell's theme code directly, so update flamenco-greeter and flamenco-shell together, then check with sudo flamenco-greeter doctor. Until then you get a text login instead of a black screen.

My password is "wrong" at the login screen but works on the desktop

The greeter uses the keyboard layout from your last sync. Run flamenco-greeter sync after changing layouts in Settings → Keyboard.

Locked in by an SDDM lock screen theme

Press Ctrl Alt Shift L on the lock screen to switch to the built-in lock.
